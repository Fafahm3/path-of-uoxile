# Path of UOxile

Servidor privado de Ultima Online (RunUO) entre amigos, com loot e craft no estilo ARPG.

Aqui fica só o **programa para jogar** (ClassicUO + Razor, já configurado).
Baixe a versão mais recente em **[Releases](../../releases/latest)**.

Para entrar no servidor também é preciso o Radmin VPN e a rede do grupo. Peça o nome e a senha da rede a quem te convidou.

ClassicUO e Razor são programas gratuitos e de código aberto, de seus respectivos autores. Ultima Online é marca da Electronic Arts. Este projeto não tem fins comerciais.
